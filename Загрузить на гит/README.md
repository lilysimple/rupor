# Рупор — лендинг

Одностраничный сайт оркестратора бизнеса на AI-агентах. Без сборщика и зависимостей:
статический HTML, CSS и JS, которые можно положить на GitHub Pages как есть.

## Структура

```
index.html                      разметка страницы
assets/
  css/prism.css                 дизайн-система PRISM: токены, типографика, компоненты
  css/prism-v2.css              слой v2: стекло, объём, 3D-подложка, тёмная тема
  js/ui.js                      интерфейс: печатающийся заголовок, кольцо героя,
                                бургер-меню, вкладки, появление секций по скроллу
  js/scene.js                   3D-сцена: пылевое ядро, кольца, звёзды, привязка к скроллу
  js/vendor/three.min.js        three.js r160 (vendor, не править руками)
  img/hero-crystal.webp         изображение внутри кристального кольца героя
tools/build_single.py           сборка одного самодостаточного файла
dist/index.single.html          результат сборки (можно открыть двойным кликом)
```

Порядок подключения в `index.html` важен: `ui.js` → `three.min.js` → `scene.js`.
Оба CSS-файла подключаются подряд, `prism-v2.css` переопределяет часть правил `prism.css`.

## Локальный запуск

Файлы связаны относительными путями, поэтому нужен любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Сборка в один файл

```bash
python3 tools/build_single.py
```

Скрипт инлайнит CSS и JS в теги, а картинку — в `data:`-URI, и кладёт результат
в `dist/index.single.html`. Полезно, когда сайт надо отправить одним вложением
или положить на хостинг без папок.

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
Файл `.nojekyll` в корне нужен, чтобы Pages не пытался обрабатывать содержимое
через Jekyll.

## Что стоит проверять после правок

- шапка остаётся на месте при прокрутке (`position:sticky` ломается, если у `body`
  поставить `overflow-x:hidden` вместо `clip`);
- бургер-меню на ширине ≤ 1080px: открывается, закрывается по ссылке, Esc,
  клику мимо и при возврате на широкий экран;
- вкладки в блоке «Управление голосом»: мышь, стрелки ←/→, активная вкладка
  подскроллена в зону видимости на узком экране;
- аккордеоны FAQ раскрываются, текст виден;
- горизонтальной прокрутки нет ни на одной ширине;
- в консоли нет ошибок.
